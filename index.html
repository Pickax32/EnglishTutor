0 / 15초

기본 OFF입니다. ON으로 선택하면 마이크 토글로 시작한 녹음이 완료된 뒤 음성이 서버로 전송되어 텍스트로 변환됩니다. 자동 전송과 자동 읽기는 각각 선택해야 해요.

자동 전송은 기본 OFF이며 자동 STT가 ON일 때 선택할 수 있어요. 두 옵션을 켜고 새로 녹음하면 STT와 AI 채팅 API가 호출되어 비용이 발생할 수 있어요. 작성 중인 채팅 문장이 있으면 시작하지 않아요.

자동 읽기는 기본 OFF이며 위 두 옵션이 ON일 때 선택할 수 있어요. 새 AI 답변을 화면에 표시한 뒤 영어로 읽어요. 재생되지 않으면 답변 듣기를 직접 눌러 주세요. 다음 녹음은 마이크 버튼으로 시작하세요.

자동 STT OFF · 변환 버튼을 눌러 수동으로 변환해요.

마이크 버튼을 한 번 누르면 녹음을 시작하고, 다시 누르면 종료해요. 시작·종료 처리 중에는 잠시 기다려 주세요.

최대 15초 · 자동 STT OFF에서는 변환 버튼을 누를 때만 음성이 서버로 전송돼요. ON에서는 마이크 토글로 시작한 녹음을 완료하면 자동으로 전송해요. 새 녹음을 시작하거나 화면을 나가면 녹음과 변환 결과가 지워져요.

녹음 시작을 눌러 내 목소리를 연습해 보세요.

수동 녹음은 종료 후 변환 버튼을 누르세요. 자동 STT만 선택하면 텍스트 변환까지만 하고, AI 자동 전송도 선택하면 채팅으로 보내요. 자동 읽기까지 선택한 새 토글 녹음은 AI 답변을 영어로 읽어요.
